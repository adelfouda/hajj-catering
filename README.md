# نظام إعاشة الحجاج

تطبيق ويب من ملف واحد لإدارة طلبات الإعاشة والتنفيذ والفواتير والمستخدمين والصلاحيات.

## الملفات
- `index.html` — التطبيق كامل
- `firebase-config.js` — بيانات مشروع Firebase
- `firestore.rules` — قواعد قاعدة البيانات
- `firebase.json` — إعدادات النشر

## النشر على Firebase
١. أنشئ مشروع Firebase وفعّل Firestore، وأضف تطبيق ويب.

٢. الصق بيانات الإعداد في:
```
firebase-config.js
```

٣. اربط المجلد بالمشروع وانشر:
```
firebase use --add
firebase deploy
```

## ملاحظة
بدون بيانات Firebase يعمل التطبيق محليًا ويحفظ في المتصفح فقط.
